Photos for the Delivery Locations page, one folder per button:

  Cold Mill / Hot Strip / BOF-Caster / Blast Furnace / Out Of Plant

- Each photo dropped into a button's folder shows up under that button as a
  location, named after the file (for example "Loading Dock A.jpg").
- A subfolder inside a button's folder becomes one location holding all of
  its photos (for example "Out Of Plant/Gate 4/1.jpg, 2.jpg").
- Each button only reads its own folder. Locations and photos added by hand in
  the app still work alongside these.
- New button? Make a folder with the same name (letters and numbers are what
  count, so "BOF/Caster" matches "BOF-Caster").

First time only: open Delivery Locations in Chrome or Edge on a computer,
select "Link photo folder" and pick this delivery-locations folder.
Supported photo types: JPG, PNG, WEBP, GIF, BMP, AVIF.
