Photos for the Delivery Locations page, one folder per button:

  Cold Mill / Hot Strip / BOF-Caster / Blast Furnace / Out Of Plant

Photos now live in the cloud (Supabase Storage), so every device sees them.
This folder is a convenient place to collect them before uploading.

- Each photo in a button's folder becomes a location named after the file
  (for example "Loading Dock A.jpg").
- A subfolder inside a button's folder becomes one location holding all of
  its photos (for example "Out Of Plant/Gate 4/1.jpg, 2.jpg").
- Each button only shows its own folder. Locations added by hand still work.
- Folder names match buttons by letters and numbers ("BOF/Caster" = "BOF-Caster").

To upload (owner or admin): open Delivery Locations, select "Upload a folder"
and pick this delivery-locations folder. "Upload photos" adds photos to the
button that is open. Supported: JPG, PNG, WEBP, GIF, BMP, AVIF (up to 20 MB each).
